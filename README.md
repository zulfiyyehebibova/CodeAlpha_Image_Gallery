🎬 Cartoon Image Gallery - CodeAlpha Internship
This is my first project as a Web Development Intern at CodeAlpha (May 2026 Batch). It is an interactive,fully responsive image gallery featuring filtering capabilities and a modern UI.

## ✨ Features
* **Dynamic Filtering:** Users can filter images by cartoon categories using interactive buttons.
* **Interactive Lightbox:** Clicking on any image opens it in a full-screen modal (lightbox).
* **Navigation:** The lightbox includes "Previous" and "Next" buttons to navigate seamlessly.
* **Responsive Design:** The layout is fully optimized for mobile, tablet, and desktop screens.

## 🛠 Technologies Used
* **HTML5:** For semantic structuring of the gallery.
* **CSS3:** For modern styling, including glassmorphism effects and responsive layouts.
* **JavaScript (ES6+):** For filtering logic, DOM manipulation, and lightbox functionality.
* **FontAwesome:** For the navigation icons.
